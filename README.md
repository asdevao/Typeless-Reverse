# Utterly

**说话，别打字。**

按一下热键说话：本机转写、大模型润色，整理好的文字直接贴进当前输入框。

## 安装（Windows）

运行发布产物里的 **Utterly-Setup-x64.exe**，双击安装。装完自动启动，首次引导带你完成配置（选识别方式、填模型 key、测麦克风和热键）。

> 语音识别模型（约 800 MB）首次使用时自动下载，支持断点续传。

## 怎么用

- **听写**：按一下热键（默认右 Alt）开始说话，再按一下结束，文字自动贴进当前输入框
- **翻译**：按住热键（默认右 Ctrl）说完，贴出译文，目标语言在设置里选
- **问任何事**：按住热键再按空格，这次录音会被当作提问，回答显示在结果卡片里
- **历史**：主窗口按天回看说过的话，可复制、可重试
- **换模型**：设置里随时换润色的大模型（DeepSeek、GLM、MiniMax……或任何 OpenAI 兼容的自定义服务），转写模型也能换本机/云端

## 三种识别方式

- **转写 + 润色**：本机模型转写（声音不出门），文字交给大模型整理，两跳各自换模型
- **原生**：录音直接交给多模态模型，一步出成品
- **数据隐私**：全本机转写，原文直出，不上传、不要 key

## 隐私

转写和润色模式下，你的声音只在本机处理，上传给大模型的只有转写出的文字；数据隐私模式完全离线。所有数据（配置、key、历史、录音）都在本机 `%USERPROFILE%\.utterly` 目录里，删掉这个目录就彻底清除。
